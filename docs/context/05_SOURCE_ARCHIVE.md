## 历史原型图

`assets/` 中保存当前阶段相关视觉稿和截图，包括：

- 第一版较密集的 Fielora 工作台；
- 第二版简化后的 Field Runtime 工作台；
- 进一步收敛后的 Field Runtime Spec 界面；
- 用户拿来评审的 Fielora 页面截图；
- Chrome 新特性截图。

这些图不是最终视觉规范。它们用于理解：

1. 为什么早期 UI 被认为过于杂乱；
2. 为什么头像 / Settings 去重；
3. 为什么 Field State、Working Set、Evidence、Activity 不应全部常驻；
4. 为什么最终强调“能力常驻系统，不常驻屏幕”；
5. 为什么 Chrome 更新进一步推动 Fielora 把 Browser UI 降级为基础设施。

Codex 在做视觉实现前应查看这些历史资产，但必须以最新 Interaction Spec 和 Project Reality 为准，不能把历史原型当最终定稿。
